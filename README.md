# ESP32 Wii Controller Kicad

This is the PCB of our custom Wiimote.
Electrical Plan and PCB made entirely by Geekoje.

## Tools used :

- Kicad

## What is inside this kicad

- ESP32 Dev Module NodeMCU from JoyIt
- Accelerometer ADXL345
- OLED Screen SSD1306
- Distance Sensor VL53L1X
- JOYSTICK ADA512
- 8 buttons
- 4 Green LEDS
- resistors (check pdf)

## Note
The connection of the Distance Sensor VL53L1X is inverted in the PCB V1
